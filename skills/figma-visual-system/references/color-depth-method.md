# Color, Material, and Depth Method

## Two truths

```text
SYSTEM
meaning -> semantic role -> variable/style -> mode -> consumer

PERCEPTION
backdrop + adjacent hue + temperature + lightness + chroma
+ occupied area + repetition + material -> perceived result
```

Neither truth certifies the other.

## Direct-perception proof

For a material color change:

1. render candidate on its real surface and at real occupied area;
2. compare one nearby alternative changing one major variable only;
3. inspect whole-scene hierarchy and local adjacency;
4. check semantic/accessibility obligations;
5. stress another representative state/mode/consumer.

Useful one-variable comparisons:

- warm vs cool neutral field with identical accent;
- same hue with lower/higher chroma distribution;
- same palette with different occupied accent area;
- stronger surface lightness separation vs additional shadow.

## Depth cue set

Use the smallest coherent combination of:

- surface tone;
- divider/border;
- spacing/alignment;
- clipping/silhouette;
- overlap/occlusion;
- shadow;
- scrim;
- translucency/blur;
- scale/transform;
- motion during actual plane change.

## Alpha rule

A translucent brand/accent value is backdrop-dependent. Treat `color @ alpha` as a compositing relation, not a fixed lighter color. Check every material backdrop it can occupy.

## Accessibility boundary

Contrast/accessibility is a hard constraint/evidence layer. It does not by itself prove hierarchy, harmony, material clarity, or visual mass. Pair color-only state/status meaning with another appropriate cue when meaning must survive color-vision or low-contrast conditions.
