# Distillation provenance

Use this file only when auditing/updating **figma-verification**, resolving evidence conflicts, or explaining its independent boundary.

## Derived design/method basis

- SDLC Intelligence / evidence-verification: claim-to-proof matching, exact revision binding, dimension-preserving evidence states, no uplift from validator/provider acknowledgement alone.
- SDLC capability boundary: verification earned a first-class Skill because fixed-artifact assessment has independent triggers, read-only authority, mechanism, output, and falsifiable completion.
- Product Design visual proof: structural conformance and visible craft are separate obligations; acceptance must not redesign the artifact.

## Installed Figma plugin Skills compared

Installed Figma Skills already require structural + screenshot proof during library/design authoring and distinct motion context for temporal implementation. This Skill extracts the **assessment outcome** without copying those authoring workflows.

## Public Agent Skill comparison

Public Figma agent ecosystems expose lint/accessibility/component/design-system inspection as reusable audit outcomes. They support Skill-worthiness but are not acceptance authority or provider truth.

## What this Skill distilled

- **Adopted:** fixed target + expected truth -> select evidence dimensions -> inspect -> per-dimension state -> bounded verdict -> repair owner.
- **Not copied:** no generic mega-linter, no design repair during acceptance, no blanket accessibility/quality score.
